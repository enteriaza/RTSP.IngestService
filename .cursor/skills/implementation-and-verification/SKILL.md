# Implementation and verification

1. Inspect callers, ownership, and tests first.
2. Make the smallest correct change.
3. Build and run the relevant tests; report exact results.
4. Preserve git safety: no stage/commit/push unless asked.
5. Stop for genuine blockers; otherwise finish the requested workflow.
